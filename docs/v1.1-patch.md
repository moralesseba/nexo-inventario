# Segunda versión (v1.1.0) — cambio para el segundo despliegue

La evaluación exige demostrar el despliegue de **al menos dos versiones
sucesivas**. La v1.0.0 es la aplicación base. Para la v1.1.0 se agrega un
endpoint de "bajo stock" que apoya la reposición del almacén.

## Paso a paso

1. En `src/controllers/productos.controller.js`, agrega esta función y expórtala:

```js
async function productosBajoStock(req, res, next) {
  try {
    const umbral = parseInt(req.query.umbral, 10) || 10;
    const { rows } = await db.query(
      'SELECT id, nombre, sku, precio, stock, categoria FROM productos WHERE stock <= $1 ORDER BY stock ASC',
      [umbral]
    );
    res.json({ data: rows, total: rows.length, umbral });
  } catch (err) {
    next(err);
  }
}
// añade productosBajoStock al module.exports
```

2. En `src/routes/productos.routes.js`, agrega la ruta **antes** de `/:id`:

```js
router.get('/bajo-stock', ctrl.productosBajoStock);
```

3. En `package.json`, sube la versión a `"version": "1.1.0"`.

4. Agrega una prueba en `tests/productos.test.js`:

```js
it('GET /api/productos/bajo-stock lista productos con stock bajo', async () => {
  db.query.mockResolvedValueOnce({ rows: [{ id: 4, nombre: 'Detergente 1kg', sku: 'LIM-005', precio: 3290, stock: 8, categoria: 'Limpieza' }] });
  const res = await request(app).get('/api/productos/bajo-stock?umbral=10');
  expect(res.status).toBe(200);
  expect(res.body.umbral).toBe(10);
});
```

5. Commit, etiqueta y publica para disparar el segundo despliegue:

```bash
git add .
git commit -m "feat: endpoint de productos con bajo stock (v1.1.0)"
git tag v1.1.0
git push origin main --tags
```
